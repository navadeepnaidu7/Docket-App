# Portable agent guidance

These are copies of the local design skills and global guidance customized on 2026-10-27, included here so the instruction changes can be versioned with this project.

- `skills/`: customized `high-end-visual-design`, `improve-ui`, `ui-design`, and `anti-ui-slop` packages, including their referenced resources and license notices where provided.
- `global-AGENTS.md`: the global Codex guidance at the time of export.
- The repository's active project instructions remain in the root `AGENTS.md`.

The skill copies are a portable snapshot; committing them does not install or activate them automatically. To restore them elsewhere, review the destination's existing customizations before copying the selected skill folders into its personal skills directory. Review and merge global guidance rather than overwriting unrelated instructions.

Third-party package manifests and checksums describe their upstream distributions. Local customization notices identify modified instructions; those upstream checksums are not validation hashes for this snapshot.
